## Overview

The Budget Process Manager tracks the lifecycle of budgets by replaying domain events from the [[container|EventStore]]. It computes current remaining amounts for weekly and monthly budgets and produces a [[command|SendTelegramMessage]] gateway command when a notification should be dispatched.

Two triggers drive the manager:

- **Reactive** — on [[event|BudgetExceeded]] and [[event|BudgetTransactionTracked]], it evaluates whether a budget threshold has been breached and sends an alert.
- **Scheduled daily** — a background job runs every morning at 8 AM, replays the full event store, builds an HTML-formatted status message with color-coded indicators (🟢 ≥50% remaining, 🟡 ≥25%, 🔴 otherwise), and sends [[command|SendTelegramMessage]] to the [[service|TelegramGateway]].
